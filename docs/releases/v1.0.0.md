# More GenUI 1.0.0

## 从一道题试起

打开扩展弹窗，把「回答增强」切到「按需」。输入「二分查找这一步之后，目标还可能在哪一半？」并点输入框旁的「仅增强本条」，然后发送。也可以在已有回答里选中一段话，选择要图解、预测题还是分步演示，再把提示追加到草稿。发送前仍可编辑。

练习支持单选、多选、数值容差和排序。第一次答错后再试，完成页仍会把这道题计入首次答错，可以单独重练。分步演示支持前进、后退、变速播放和重新开始。重新打开同一个兼容应用，会恢复题目或步骤。普通短答继续使用普通文字。

## 把两次实验放在一起

打开应用上方的「实验工具」，把当前参数保存为命名快照，或点「锁定 A」后调整 B。以固定周长 20 cm 的矩形为例，5 × 5 时面积是 25 cm²，改为 7 × 3 后是 21 cm²，差值 B−A 为 −4 cm²。指标按名称和单位配对，曲线还要求坐标轴与单位兼容。[可直接读取的示例源码](../../examples/perimeter.html)

每个应用作用域最多保存 24 个快照。JSON 导出当前参数。表格 CSV 及图形 PNG 取自应用主动登记的数据与 SVG 或 Canvas，剪贴板功能依赖浏览器授权。普通回答里的规则双列表格支持原表、柱状图、折线图切换；缺失值保留为空，同列单位混杂时保留原表。

## 核对检索回答

扩展弹窗可选「图文」「仅文字」「关闭」。来源卡读取 DeepSeek 的正式搜索记录，引用所在小节可直接打开原网页，文末「全部检索来源」也保留未匹配的条目。没有封面也能核对文字来源。文本记录与缩略图分开存储，文本记录保留七天、最多 256 条回答。缩略图仍受 7 天和 10 MiB 的缓存限制。仅文字模式无需访问来源网站。

## 给生成应用的接口

- 原有 HTML 元数据和 `genui.getState()/setState()` 沿用原契约。
- `genui.quiz.mount(el,{id,questions})` 接受 `single`、`multiple`、`number`、`order`。多选与排序的 `correct` 为 ID 数组，数值题使用数字、非负容差和可选单位。
- `genui.stepper.mount(el,{id,steps:[{title,text}]})` 由宿主管理步骤与播放。
- `genui.experiment.publish({metrics,rows,figure,presets,series})` 按需登记结果，参数变化后重新调用。示例源码给出了可运行的写法。
- `genui.capabilities` 提供能力版本。可在应用元数据之后、HTML 之前添加 `<!-- more-genui-requires: {"quiz":2} -->`。本版遇到不支持的声明会在运行应用脚本前给出提示。

## 安装、升级和回退

1. 解压扩展 ZIP，把文件放到原先加载的目录，保留扩展 ID。在 Edge 或 Chrome 的扩展管理页重新加载，再刷新 DeepSeek 页面。浏览器弹窗可独立调整生成模式与来源显示。旧版关闭配图的设置映射到「仅文字」。
2. Harness 使用同版本 TGZ。解包后，按原 Web profile 安装或替换包含 `package.json` 的插件目录，再重启 `dsh web`。宿主继续使用 Harness 0.2.1-rc.5 与 Cordis 4.0.5。
3. 回退时在同一目录恢复 0.5.1 ZIP，重新加载并刷新。Harness 换回 0.5.1 TGZ。请先导出需要留存的实验参数；旧版只支持其已有的题型与接口。
4. 校验安装包可运行 `Get-FileHash -Algorithm SHA256 <文件路径>`，与安装包旁的 `SHA256-v1.0.0.txt` 核对。
