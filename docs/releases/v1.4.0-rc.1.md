# More GenUI 1.4.0-rc.1

先问一句「为什么 B 能推出 ε 时，求 FIRST(A) 还要看 C？」。这道题可以用三句话回答，也可以拿同一个文法观察 B 可空时的变化。默认 Auto 沿用原版策略 A。弹窗里的 Auto B 使用新的选择规则和 HTML；Auto C 使用同样的选择规则，并提供 Fast UI。偏好可视化是另一个主动选项。

## 教学卡

扩展接受完整的 `genui-json` 围栏，Harness 使用 `render_visual({spec})`。根对象包含 `version:1`、`stateVersion`、`id`、`title` 和 `kind`。每个视图把自己的字段与 `kind` 放在同一层。模型可以使用单块，也可以在解释之间放多块。现有 `genui-html` 与 Harness 的 `render_app` 继续可用。

- [文法对照](../../examples/lessons/left-recursion.json)、[可空传播](../../examples/lessons/nullable.json)和[分析表冲突](../../examples/lessons/conflict.json)可用来核对 FIRST、FOLLOW、SELECT、直接左递归及输入分析轨迹。点击计算得到的冲突格可查看产生式进入该格的依据；要改变结果，修改文法后点「重新计算」。
- [自动机](../../examples/lessons/automaton.json)允许编辑状态和含 ε 的边。重新计算后选择 DFA 状态，可以看到对应的原状态子集。子集数上限为 256。
- [BFS](../../examples/lessons/bfs.json)用可回退的步骤显示队列；[欧姆定律](../../examples/lessons/ohm.json)演示电阻固定时电流如何随电压变化。同一回答的卡片可声明相同的 `group`，共享文法或具有相同 ID 的条件选项。
- 在模型编写的矩阵解释、对照注释或节点说明上点「修正这里」，输入新文本，预览后采纳。改动绑定当前源码修订。教学卡的更多操作可保存 PNG 或独立 HTML；离线 HTML 带上导出时的状态，用浏览器打开即可操作。
- 「本对话图解」按标题定位本次浏览已观察到的模块。虚拟列表中先恢复滚动位置，再按消息和应用标识确认目标。弹窗可开启「学习我的表达偏好」；对三个不同回答使用同类选区操作后可采纳建议，清空按钮同时移除选择记录与偏好。

## 真实评测

候选构建通过类型检查、生产构建、33 项快速测试和 92 项 Chromium 回归。100 条消息、20 个应用的长对话回放在暂停后测得 0 个活动播放计时器。两个安装包均已解包并与本地构建内容核对。

自然题共 50 道。执行 `node scripts/prompt-lab.mjs` 会生成冻结的 48 次调度，每次只发送调度中的 prompt。每次开新对话，在同一官网模式交错完成 12×3 次，再切换官网模式完成 4×3 次。关闭个人偏好并启用开发诊断，用实际发送的策略哈希核验注入。评分记录通过 `scripts/lab-record.mjs` 导入；`node scripts/prompt-lab.mjs score .cache/prompt-lab/records.json` 统计首轮结果。文字可以获得完整的语义与任务完成分。历史显式提问已单独保留。

## 安装、升级与回退

核对 `dist/SHA256-v1.4.0-rc.1.txt` 后，解压扩展 ZIP 至原加载目录，保持扩展 ID。在扩展管理页重新加载并刷新 DeepSeek。新装先显示文字来源；开启图文时浏览器会请求 HTTPS 来源权限，可在弹窗撤销。取图会让目标站点看到 IP 和请求时间。

Harness 使用同版本 TGZ，解包后选择含 package.json 的目录，按原 Web profile 安装插件并重启。宿主版本为 0.2.1-rc.5。

回退前导出要保留的教学卡和实验参数。在原目录恢复 1.0.0 ZIP 并重新加载，Harness 换回 1.0.0 TGZ。旧版可打开原有 HTML 应用；新格式的教学卡可以继续用已导出的独立 HTML 打开。
