# More GenUI 0.5.1

两个回答同时生成、又都缺少可靠消息标识时，即使页面已经显示 `</html>`，扩展也会等待可归属的围栏确认。仍有歧义的完整应用可在生成停止后点“运行此应用”。同一会话发生重叠后，后续拿不到可靠标识的新代码也会采用保守的手动路径。已有实验和测验沿用原存储键。

浏览器工具栏里点击 More GenUI 即可单独关闭“搜索配图”。默认开启，沿用安装时的 HTTPS 来源权限。关图会取消取图并撤下缩略图。重新开启时，历史回答先读本地缓存，新检索照常取图。慢网站不会挡住另一个标签页恢复缓存。图片保留七天，预算 10 MiB，由扩展自己的 IndexedDB 保存。

## 升级与回退

1. 先保留 0.5.0 的 ZIP。将 0.5.1 解压到原来加载的同一个扩展目录，在扩展管理页点“重新加载”，再刷新 DeepSeek。保留原扩展 ID 才能读取旧图和答题进度。
2. 首次升级迁移会保留有效图片原有的到期时间。迁移成功后才移除旧缓存，重新启动可以接着处理。
3. Harness 按原安装方式换用 0.5.1 TGZ，宿主仍锁定 0.2.1-rc.5。
4. 需要回退时，将原目录换回 0.5.0 的文件并重新加载。旧版可继续读取应用状态，但无法显示已经迁入 IndexedDB 的旧图。Harness 可重新安装 0.5.0 TGZ。

## 验收

- 本地类型检查和生产构建通过。18 项快速测试、12 项 Chromium 回归通过，覆盖并发和取消、官方导航、Fetch/XHR 修复、独立开关、跨标签页恢复，以及迁移后保持答错反馈阶段。
- 迁移回放构造了“新库已写入、旧键尚未删除”的中断点，停止 Service Worker 后重新打开回答。网络边界回归先验证受控域名能访问回环 HTTPS 服务器，再从实际取图路径发起请求，服务器未收到探测路径。[本地回归记录](../evidence/v0.5.1-verification.json)
