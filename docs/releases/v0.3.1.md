# More GenUI 0.3.1

修复后的代码明明有完整 HTML，为什么还是不显示？这次是宿主的文档起始检查太严格：元数据后只接受 `<html>` 或 doctype，而模型把 `more-genui-repair` 注释放在了 `<html>` 前面。

现在允许元数据与 HTML 之间出现完整注释，保留注释供显式修复交接使用。不改变元数据协议，也不放宽未闭合 HTML、未闭合注释或任意正文的检查。

本地验证：类型检查、生产构建、13 项快速测试通过；基于用户修复版缓存练习的 Chromium 定向回归通过，覆盖三题选择、下一题、完成状态和重置。原版只提供了题库定义片段，不能据此确认其不能翻题的具体原因。本次未做真实官网生成验收，也未重跑全部浏览器矩阵。

更新包为 `dist/more-genui-extension-0.3.1.zip` 和 `dist/more-genui-harness-0.3.1.tgz`，校验值在 `dist/SHA256-v0.3.1.txt`。扩展重新加载后刷新 DeepSeek 页面，历史完整修复代码即可按既有历史渲染规则重新识别，无需再让模型生成一遍。页面刷新会清除尚未消费的内存修复快照，不承诺恢复更新前未完成的参数交接。

保留 `v0.3.0` 与原安装包用于回退；本补丁使用新标签 `v0.3.1`，只作本地提交，不推送远端。
