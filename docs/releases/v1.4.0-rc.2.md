# More GenUI 1.4.0-rc.2

在 DeepSeek 的二分教学卡里点「下一步」，再点「比较上一步」，可以对照区间、单元格或图中节点的变化。点「上一步」回到原来的步骤。文法编辑器会保留最新输入的错误提示，旧计算返回时不会覆盖它。

带完整协议的普通 HTML 或 JSON 示例现在提供「点击预览」。沙箱握手后才收到应用；打包页面未应答时，宿主尝试一次内嵌沙箱。仍无法启动时可查看源码并保存离线卡。开发者可以在诊断面板复制某次请求的阶段、耗时和策略哈希。

## 验收

- 官网内置浏览器复用原二分卡，实际前进、比较、回退，核对区间 `[0,4] → [3,4] → [0,4]`。[官网截图](../evidence/v1.4-rc2-binary.jpg)
- 官网新增两问。第一问生成文法卡，删掉 B 的空产生式并重新计算，FIRST(A) 从 {a,c} 变为 {a}。第二问要求一句话定义终结符，收到文字短答。
- 类型检查和生产构建通过。快速测试 35 项、完整 Chromium 98 项通过。最后统一离线导出的握手逻辑后，再次运行快速测试及离线卡、沙箱回退两项定向回归，均通过。官网操作发生在这项离线导出调整前。
- 本地 PR 工作流使用脱敏用例。远端 CI 未运行。并发后仍无法识别归属的完整应用采用手动预览。

## 安装和回退

将候选 ZIP 解压到独立目录，在扩展管理页启用开发者模式并加载该目录，再刷新 DeepSeek。Harness 使用同版本 TGZ 替换原本地包。回退时重新加载保存的 rc.1 扩展目录，Harness 重新安装 rc.1 TGZ。两个候选使用相同状态键。
