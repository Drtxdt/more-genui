# More GenUI 0.3.0：先把该保留和不该串用的东西分清

应用能跑以后，最容易被忽略的是什么？不是再加一个按钮，而是第二条消息、半截回答和切换会话这些日常操作。0.3 主要补这条链路，同时把场景从数学实验扩到六类常见问题。

## 这次改了什么

- **消息状态隔离。** 存储键包含宿主、会话、稳定消息/工具调用标识、应用 ID、同名出现次序和状态版本。同名新应用从自己的状态开始。没有稳定消息标识时使用页面内临时仓库，刷新或虚拟列表重建不承诺恢复。
- **修复是一次明确交接。** 点击修复时截取当前参数，生成一次性标识；模型需在返回 HTML 内回显注释。仅同会话、同 ID、兼容状态版本的结果能消费快照，扩展还核对它属于发起修复的请求。快照只在内存保存，15 分钟过期，新修复替换同会话旧请求。未回显、改了版本或刷新页面，就不自动继承。没有修改元数据 schema，也没有新增跨应用通信。
- **中断后留一个明确出口。** 当前请求只有确认完整围栏的源码自动启动。取消、网络错误或格式不兼容后，元数据与 HTML 完整但边界未确认的源码显示手动运行按钮；按钮绑定当时源码，源码变动就失效。半截文档不执行。
- **历史内容的例外。** 按本轮选择，历史消息中的完整协议 HTML 自动运行，即使扩展没观察到原始结束围栏。页面加载时无法判断服务器保存的历史是否曾中断，这是明确保留的行为。
- **官网适配集中管理。** 正文选择器移入小型 DeepSeek DOM 适配模块，排除导航、预览和自身节点。消息内容变化只扫描变更消息；结构发现仍观察页面子树，以便发现虚拟列表重建。路由变化清理请求归属与挂载，失效时移除监听并恢复原节点。
- **开关不抢跑。** 初始关闭，读到本地设置后才启动；读取失败保持关闭并允许重试。MAIN/内容脚本通过事件握手同步，不再每秒轮询。
- **共享运行时。** 保留一行七个 Lucide 操作图标；本地 form 的点击、Enter 和 requestSubmit 可以触发计算，但不允许实际提交或导航。超过 1200px 的内容折叠，展开保留原 iframe；20000px 是异常显示上限，超过会提示。
- **六类场景。** 数据探索、方案比较、分步算法、知识关系、时间规划、实用计算各有离线参考样例，生成指令加入对应的语义边界。模型仍自主选择是否需要 UI，不添加模板选择器。

## 本地验收与边界

本轮使用类型检查、生产构建、12 项快速协议/状态/Harness 服务测试，以及 Chromium 的 14 项定向浏览器回归。浏览器使用模拟官网响应，没有登录真实 DeepSeek。结果快照见 `docs/evidence/v0.3-browser-results.json`，共享界面截图见 `docs/evidence/v0.3.0-toolbar.png`。

覆盖请求附加、XHR、确认围栏、手动恢复、导航重复文本、路由迟到事件、同名隔离、稳定消息重建、显式修复交接、主题、同实例放大、本地表单与长内容展开，以及六个场景的固定预期值。没有重跑旧版 20 次生成/100 项双浏览器矩阵。

**官网实际生成与 Edge 人工体验待用户手测。** 本轮未将本地参考样例当成模型生成质量，也未将 Harness 服务测试当成真实 Harness 客户端全链路验收。手测提示词在 `docs/test-prompts.md`，按兴趣挑几题即可。

性能记录见两个 `v0.3-*-benchmark.json`。固定 1/10 应用长回答分别比较旧全量围栏扫描和已知 APPEND 增量扫描；DOM 比较 100 条消息全扫描与单条变更扫描。它们只测相应阶段，不包含模型、网络、布局、iframe 启动或整页内存，也不能换算成官网提速比例。SET/重写仍允许重新解析，离屏暂停和硬 CPU 配额不在本轮范围。

沙箱继续只允许脚本、禁止联网与表单导航；自由 JS 仍可能长时间占用线程。高度限制是显示边界，不是计算资源隔离。网站私有 DOM/API 改动也可能需要重新适配。

## 安装、更新与回退

扩展包：`dist/more-genui-extension-0.3.0.zip`。解压，在 Edge/Chrome 开发者模式加载包含 `manifest.json` 的目录。已加载 `.output/chrome-mv3` 的用户，重新加载扩展后刷新 DeepSeek 页面。

Harness 包：`dist/more-genui-harness-0.3.0.tgz`。安装方式沿用 `packages/harness/README.md`，宿主仍锁定 0.2.1-rc.5。SHA256 位于 `dist/SHA256-v0.3.0.txt`。不迁移历史参数，建议用新生成内容验收。

本轮只创建本地提交与 `v0.3.0` 标签，不推送远端。要回退，可以加载之前保留的 0.2.1 安装包，或者在独立目录构建旧标签：

```powershell
git worktree add ../more-genui-v0.2.1 v0.2.1
cd ../more-genui-v0.2.1
pnpm install --frozen-lockfile
pnpm build
```

再加载那个目录下的 `.output/chrome-mv3` 并刷新官网。别直接拿旧构建覆盖正在修改的工作区，省得修一个问题顺便送自己一个新问题。
