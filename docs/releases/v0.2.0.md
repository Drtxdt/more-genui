# More GenUI 0.2.0

## 本次更新

- 修复附加指令折叠误处理官方右侧导航：处理范围限制为 `.ds-message` 正文，助手应用限定于 `.ds-assistant-message-main-content`。无法确认归属的节点不处理。
- 页面变更观察只对消息相关变化触发内容扫描；关闭/失效时恢复原始隐藏节点。
- 共享外壳去掉常驻标题，使用 Lucide 放大与更多图标，管理功能集中在菜单，异常显示修复入口。
- 小型静态图解按内容高度显示，不再强制 200px；放大保留原 iframe。
- 增加主题变量、基础控件与布局类。提示词鼓励静态示意、参数探索和分步过程按需要穿插，减少重复说明和装饰性大面板。
- 右下角电源开关具有约 500ms 激活动效，支持减少动态效果设置，刷新不会重播。
- Lucide 图标本地打包，许可证随两种安装包分发；没有新增网络权限。

## 验收

类型检查、生产构建及 10 项快速测试通过。5 项 Edge 回归通过：请求附加/恢复、完整围栏门控、XHR、官方导航重复文本隔离、紧凑高度/菜单/主题/同实例放大。结果见 `docs/evidence/v0.2-browser-results.json`，截图见 `docs/evidence/v0.2-inline.png`。

尚未完成：振幅与频率、二分查找、二项分布三个问题的真实官网人工查看。Computer Use 无法可靠识别当前 Edge 页面的 URL，触发停止；没有把本地模拟网络回归当作官网验证。本次未重跑旧版 20 次生成或 100 项浏览器矩阵，旧验收报告只代表 0.1.0。

## 安装与升级

扩展安装包为 `dist/more-genui-extension-0.2.0.zip`。解压后在 Edge 扩展页加载包含 manifest.json 的目录。若原来直接加载项目 `.output/chrome-mv3`，点击扩展的重新加载，再刷新 DeepSeek 页面即可。必须刷新旧页面，清除先前版本插入的导航节点。

Harness 安装包为 `dist/more-genui-harness-0.2.0.tgz`，也可继续使用已构建的 `packages/harness` 目录安装。锁定 Harness 0.2.1-rc.5。开发阶段不提供历史应用换肤或参数迁移，视觉验收以新生成内容为准；旧源码自定义配色仍可能覆盖基础样式。

## Git 与回退

采用 Conventional Commits，修复、共享界面、开关和文档分别提交，仅本地版本控制，无远端推送。`v0.1.0` 保存原始基线，`v0.2.0` 标记本次代码。

回退优先加载仍保留的 0.1.0 安装包；或在独立目录检出 `v0.1.0` 后构建，避免覆盖当前工作：

```powershell
git worktree add ../more-genui-v0.1.0 v0.1.0
```

进入该目录后执行 `pnpm install --frozen-lockfile` 和 `pnpm build`，加载对应构建。安装包校验值位于 `dist/SHA256-v0.2.0.txt`。
