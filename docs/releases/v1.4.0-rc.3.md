## 为什么保留候选标记？

11 类都有回答内操作记录，但「点到了控件」不等于「第一次回答就办完事」。备餐卡切人数和保存勾选成功，却没给采购单复制操作；储蓄题能给出正确数字，首答仍不能调利率。最终打包的 C 已明确写出围栏格式和对可调数值的要求，此提示改动晚于官网采样，尚未取得相同样本的改善证据。

匿名请求采用每次实际发送的独立标记，与流中闭合围栏的语言、次序和源码共同核验。回放让两个请求重叠结束，新的匿名请求正常挂载，滚回去重建的旧卡没有继承新请求的修复参数。没有可核实的来源时仍可显式预览完整代码。

官网另外两条短问（终结符、水平视场角）各得到一句话定义，没有插卡。重验旧二分卡，回退到 [0,4] 再前进到 [3,4]；文法卡删除 B → ε 后得到 FIRST(A)={a}。11 个文件均经过 Harness 注册工具的实际调用。

本地类型检查、生产构建、36 项快速测试、109 项 Chromium 和 13 项定向 Edge 回归通过。从两个 ZIP 解压，在干净 Chromium 和 Edge 配置中从 rc.2 原地升级到 rc.3，带稳定消息键的历史卡振幅仍为 1.8。没有稳定键的历史消息只用临时状态，跨浏览器重启不承诺恢复。未验品牌 Chrome 的干净配置安装。本提交远端 CI 未运行；未打正式标签。

## 四道同题：观察到了什么？

| 题目 | ChatGPT 首答 | DeepSeek 加扩展 |
|---|---|---|
| 备餐 | 点 6 人后为羊排 1500 克、土豆 1200 克，采购项可勾选 | 手动预览后同量，勾选和人数刷新可恢复 |

| 蒙提霍尔 | 选 1 后主持人开 2，可以换到 3、揭晓或重放 | 追问后可换门、重放，检查了重放时门号不变 |
| 分账 | 应付 8.96 和 30.72，合计 39.68；未核实可编辑的分摊控件 | 首答同样金额；追问后实际改小费，金额随之更新 |

刷新匿名 ChatGPT 的备餐页返回首页，没有验证到进度恢复。两边未形成完整的逐题耗时、步数及离线恢复配对，不据此宣称更快或整体超越。网页曾返回「有消息正在生成，请稍后再试」；上表将拒绝、重发及明确要求代码围栏的追问与首答分开。

## 升级、回退和反馈

备份旧解压目录，将候选包内容更新到原加载路径，在扩展管理页点重新加载，刷新 DeepSeek。换路径可能改变扩展 ID，旧进度不会自动转移。回退到 rc.2 时恢复原目录文件、重新加载、刷新；rc.2 无法识别新增的三种视图。Harness 沿用已锁定依赖，在原安装配置将 TGZ 换成同版本，回退时换回 rc.2。源文件和本地状态未经迁移。
